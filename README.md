# 🌐 NexaCore & Currículo — Atividade HTML/CSS

Projeto desenvolvido como atividade acadêmica na **FIAP**, aplicando os conceitos fundamentais de HTML5 e CSS3 no desenvolvimento de duas páginas web.

---

## 📁 Estrutura do Projeto

 Sites/
├── startup.html → Página institucional da NexaCore
├── startup.css → Estilos da página NexaCore
├── curriculo.html → Currículo pessoal
└── curriculo.css → Estilos do currículo


---

## 📄 Páginas

### 🏢 NexaCore — Site Institucional
Página institucional de uma startup fictícia de tecnologia focada em IA, automação e desenvolvimento de software sob medida.

**Conteúdo:**
- Apresentação da empresa e seus valores
- Tabela de serviços oferecidos
- Seção de contato com links externos

### 👤 Currículo — André Ayello de Nobrega
Currículo pessoal em HTML com informações acadêmicas, habilidades técnicas e contatos profissionais.

**Conteúdo:**
- Perfil e descrição pessoal
- Tabela de formação acadêmica e certificações
- Lista de habilidades técnicas
- Links para LinkedIn e GitHub

## ✅ Conceitos Aplicados

| Conceito | Aplicado em |
|---|---|
| Estrutura HTML | Ambas as páginas |
| Tags fundamentais | `h1`–`h4`, `p`, `ul`, `li`, `table` |
| Listas | Missão/Visão/Valores, Habilidades |
| Tabelas | Serviços (NexaCore), Formação (Currículo) |
| Inserção de imagem | Logo NexaCore, Foto do currículo |
| Inserção de links | Contato, LinkedIn, GitHub |
| CSS Inline | `style=""` direto nas tags |
| CSS Interno | `<style>` no `<head>` |
| CSS Externo | Arquivos `.css` linkados |
